姐妹们！！！谁懂啊，Mac 上用 WPS 做审计底稿，居然找不到一个能批量加 ROUND 的插件？？？

我真的忍了很久了。每次加完班对着几百个单元格手动套 ROUND，人都要裂开。

所以！我！自己做了一个！（加完班回来奴役 AI 捣鼓出来的，主打一个工作不够饱和）

装上之后你的 WPS 表格"开始"选项卡会多出来几个按钮，从此告别重复劳动，下班时间提前半小时（不是

## 这玩意儿能干嘛

### 一键 ROUND（我的最爱没有之一）

选中单元格，点一下就完事了：

- `=A1+B1` 秒变 `=ROUND(A1+B1, 2)`
- 纯数字 `0.1234` 也能直接套上 `=ROUND(0.1234, 2)`
- 想要别的精度？下拉菜单 0~4 位随便选，还有自定义
- 后悔了？"移除 Round" 一键脱掉，公式原样还给你
- 不想保留公式只要数值？"直接四舍五入"帮你算好写回去

### 正负转换

调表的时候经常要翻正负号对不对！！

- `=A1+B1` ↔ `=-(A1+B1)`
- 纯数字 `5300` ↔ `-5300`
- 选一片全给你翻过来，不用一个一个改

### 复制为 Markdown 表格

要把底稿喂给 AI 看？DeepSeek 这种纯文本模型又不认截图，直接选中区域 → 点一下 → 剪贴板里就是格式完美的 MD 表格，粘给 AI 它立马就能理解你的表格结构。当然贴到飞书/Notion/文档里也很香。

- 自动跳过你隐藏的行列（懂事）
- 合并单元格也能正确处理
- 多行表头自动识别（还能接 AI 帮你判断，但不配也完全不影响用）

## 通用特性（技术党可以看看）

- 支持不连续选区，Ctrl 点哪儿算哪儿
- 大选区批量读写，几千个单元格也不卡
- ROUND 各种奇葩分隔符都兼容（逗号句号分号中英文全认）

## 怎么装

需要：macOS + WPS Office

打开终端，两行命令搞定：

```bash
cd SheetKit
bash ./install_mac.sh
```

然后 **Cmd+Q 完全退出 WPS 再重新打开**（这步不能省，不然看不到按钮）

就这么简单。不需要什么开发者模式，不需要折腾配置文件，复制粘贴就行。

## 怎么卸载

不想用了（不会吧不会吧）：

```bash
cd SheetKit
bash ./uninstall_mac.sh
```

卸载完也记得重启 WPS。

## AI 加持（可选，不配也行）

"复制为 MD 表格"那个按钮的下拉箭头里有个"设置 LLM API"，可以接一个兼容 OpenAI 格式的 AI 接口来辅助判断多行表头。

不配的话功能完全正常，就是用规则自动判断表头，绝大多数情况够用了。

## 已知的小问题

- 有些图标在 Mac 版 WPS 上可能显示不出来（WPS 的锅不是我的锅）
- AI 表头检测要配 API 才能用，不配就自动回退规则检测
